## Project Summary
A vintage-style ecommerce landing page with a focus on high-quality typography and a nostalgic aesthetic. The project features a well-designed hero section with a ticker band and bold titles.

## Tech Stack
- Framework: Next.js 15 (App Router)
- Language: TypeScript
- Styling: Tailwind CSS 4
- Fonts: Ultra (Google Fonts)
- Animations: Tailwind CSS animations (marquee)

## Architecture
- `src/app`: Application routes and global styles.
- `src/components`: Reusable UI components.
  - `Hero.tsx`: Main hero section with ticker and vintage design.

## User Preferences
- Background color: #FFEAD3 (Vintage Cream)
- Font: Ultra (serif)
- Aesthetic: Vintage / Retro

## Project Guidelines
- Use the `ultra-regular` class for Ultra font styling.
- Maintain a cohesive vintage palette (Vintage Cream, Vintage Red).
- Prefer bold, uppercase typography for headings.

## Common Patterns
- Ticker bands for announcements or brand values.
- Centered graphic elements with bold text overlays.
