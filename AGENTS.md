## Project Summary
A high-end vintage e-commerce landing page featuring a classic aesthetic, bold typography, and a warm color palette. The goal is to create a premium, timeless shopping experience.

## Tech Stack
- Framework: Next.js 15 (App Router)
- Styling: Tailwind CSS 4
- Icons: Lucide React (standard)
- Fonts: Ultra (Google Fonts)
- Design: Vintage/Retro aesthetic

## Architecture
- `src/app`: Page routes and global styles
- `src/components`: Reusable UI components (Hero, etc.)
- `public`: Static assets

## User Preferences
- Background Color: #FFEAD3
- Primary Font: Ultra (serif)
- Design Style: Vintage/Retro, well-designed, big bold typography

## Project Guidelines
- Use the `ultra-regular` class for the Ultra font.
- Maintain a cohesive vintage color palette (Cream, Deep Red, Earthy Browns).
- Ensure high visual accuracy for hero sections and bands.

## Common Patterns
- Hero sections with large bottom-aligned typography.
- Scrolling marquee bands for brand values.
